# 语料目录（宿主半边清洗回归的扩展点）

把「清洗后必须为空」的真实片段丢进下面两个目录，`node --test` 会逐个断言
`cleanForTts(content).trim() === ""`。两个目录的判定完全相同，分开只为记录来源：

- `filtered/`：路径 / URL / Markdown 装饰符这类「清洗掉后应无残留」的片段
- `dropped/`：代码块 / 图片 / 纯装饰这类「应当整段消失」的片段

加语料只需往这里丢文件，测试自动纳入（每个目录都要求至少有一份）。文件名以 `.` 或 `_` 开头的会被跳过
（`.gitkeep` 就是靠这条规则忽略掉的）。
